🛡️ I built Rakawarana (රැකවරණ), a bilingual CRM for insurance advisors.

I work as an insurance advisor, and I saw the same problem everywhere: client details in a notebook, payment dates in WhatsApp chats, renewals and birthdays forgotten. Missed premiums mean lapsed policies, and that hurts both the client and the advisor.

So I built the tool I wanted to use myself:

✅ A "Today" list every morning: overdue premiums, upcoming dues, renewals, birthdays and follow-ups
💬 One-tap WhatsApp reminders in Sinhala or English
📈 A drag-and-drop sales pipeline from lead to client
💰 Record a payment and the next due date and commission are worked out automatically
📊 Monthly reports against my target, with PDF and Excel export
👥 A team view for branch managers that shows totals but never the client lists
🧮 Life-cover and savings calculators for client meetings

Security was a priority from day one, because this is people's personal data:
🔐 Two-step login (authenticator app and recovery codes)
🔒 NIC numbers encrypted in the database, with every view logged
🧱 Each advisor can only ever see their own records, checked on every request
🚦 Rate limiting, a strict Content-Security-Policy and an audit log

Tech: Laravel 13 · PHP 8.3 · Tailwind CSS 4 · Alpine.js · Chart.js · Vite · PHPUnit + GitHub Actions · Docker
